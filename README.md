# 🧠 Injective Action Copilot

AI-powered decision assistant that converts natural-language intent into **risk-aware, structured onchain action plans** on Injective — with human review before execution.

---

## 🚀 Overview

Injective Action Copilot helps users make better onchain decisions by combining:
- Wallet context
- Market data
- AI reasoning
- Structured transaction drafting

Instead of blindly trading or guessing, users get a **clear AI-generated plan + risk analysis + optional execution flow**.

---

## 🎯 Problem

Crypto users struggle with:
- Fragmented data (wallets, markets, protocols)
- Emotional decision-making
- No structured “review layer” before executing trades

Result: poor timing, unmanaged risk, and reactive behavior.

---

## 💡 Solution

An AI copilot that:

1. Understands user intent in natural language  
2. Reads wallet + Injective market context  
3. Generates a structured action plan  
4. Explains risks and reasoning  
5. Lets users approve or reject before execution  

---

## 🧭 User Flow

1. **Connect Wallet**
   - User connects Injective wallet

2. **Dashboard Context**
   - Portfolio summary
   - Market snapshot
   - AI prompt input

3. **Intent Input**
   - Example: *“Should I reduce exposure to volatility?”*

4. **AI Plan Generation**
   - Portfolio analysis
   - Suggested actions
   - Risk breakdown
   - Draft Injective transaction

5. **Review Screen**
   - Human-readable explanation
   - Risk flags
   - Transaction preview
   - Approve / Reject / Modify

6. **Execution**
   - User signs transaction (optional)
   - Executed on Injective

7. **Activity Log**
   - History of intents, AI outputs, and transactions
